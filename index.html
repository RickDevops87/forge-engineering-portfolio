Accessible security for every business

Forge Defense Factory

Serious security. Within everyone's reach.

What it does: Gives individuals, solo businesses and small to medium-sized teams a way to run security scans and tests on their own systems and AI applications, discover potential vulnerabilities and improve security awareness.

Why we built it: Security expertise and ongoing protection should not be reserved for companies with large budgets or dedicated security teams. We built Defense Factory to make practical, guided security capabilities more accessible and affordable.

The problem it solves: Helps organizations identify and understand weaknesses themselves, with a path to professional Forge assistance when remediation or deeper review is needed.

Our intended offering: A one-time software purchase including user training and a 12-month licence with Forge security updates. An optional monthly Forge service would provide hands-on mitigation of discovered issues and specialized Audit SWAN agent and tool assessments of software updates before production, followed by mitigation assistance where required.

Forge Activation Monitor

Know what your AI agents are doing.

What it does: Connects agent activity, tool requests and reported outcomes into an understandable investigation timeline.

Why we built it: We built it so an independent developer, a small business or a large organization can understand security-relevant AI-agent behavior without having to create its own monitoring platform.

The problem it solves: Makes agent monitoring and investigation practical for teams of any size, even when they lack a dedicated AI-security department.

Forge Audit Copilot

From complex protocols to focused audits.

What it does: Helps auditors map smart contract behavior, identify important invariants and develop targeted security tests.

Why we built it: We wanted an individual auditor or small protocol team to have the kind of structured analysis support that complex smart contract security reviews demand.

The problem it solves: Makes deeper protocol mapping and targeted security investigation more accessible, from independent audits to large multi-contract systems.

Live web & Web3 investigation

Forge CLI

See what happens beyond the interface.

What it does: Captures real browser, wallet, transaction, API and RPC activity, including exposed-key indicators and the evidence behind a user interaction.

Why we built it: We built it because smart contract code alone cannot explain the risks that emerge across the full Web3 user journey.

The problem it solves: Gives security engineers visibility into live application behavior that isolated code scans miss.

Forge CodeGraph

Reveal the connections inside Solidity.

What it does: Maps contract relationships, permissions, state access and execution paths into a navigable, source-linked picture.

Why we built it: We built it to give individual developers, small teams and enterprise auditors a clearer way to understand Solidity systems without spending days manually tracing every dependency.

The problem it solves: Makes complex contract architecture and high-value security paths easier to explore, whether the target is a single protocol or a large codebase.

Independent research · November 2026

Beyond the Weights

Why the AI Industry Must Rethink Training, Trust, Continuity and Human–AI Development

Our work extends beyond software. In Beyond the Weights, Forge founder Rick Nieuwoudt examines how AI capability is shaped not only by model training, but by the environment in which people and AI systems work together: tools, context, continuity, constructive challenge, practical experience and accountability.

The paper introduces Collaborative AI Development — an approach that treats sustained, responsible human–AI collaboration as an important part of developing reliable, useful AI systems.
